# Changelog

## 0.1.0

- First release: minimal animated rooftop PV card for the Intelbras Solar Local
  integration (day / limited / starting / standby / night / fault / offline),
  sun and moon on an arc driven by `sun.sun` with elevation-based intensity,
  weather scenes (partly cloudy, cloudy, rain, pouring, storm, snow, fog, wind),
  load bar, MPPT strings, per-state stats, power-limit toggle, clock sync and
  datalogger restart, visual editor, entity suggestion, en + pt-BR.
